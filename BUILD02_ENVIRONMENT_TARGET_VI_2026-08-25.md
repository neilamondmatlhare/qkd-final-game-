# Build 02 — Environment Target VI

**Visual north star:** `Docs/ReferenceImages/Build02_ProductionVI/00_HQ_HIGH_GRADE_TARGET.png`

Production VI is an **environment-art milestone**, not another foundational-engineering milestone.

## Locked translation rule

Keep A1–A10, room bounds, doors, IDs, colliders, WS04 and interaction anchors underneath. Visually replace the remaining greybox language with a repeated architectural kit, curated V prefab library, authored room composition and readable lighting.

The reference is decomposed as:

`canonical skeleton → architectural skin → material family → reusable commodity assets → Phantom Q hero composition → lighting → investor/player camera`

Characters are intentionally deferred.

## Whole-HQ production families

- **Operational / corporate:** Reception, Central Operations, Foundations, Communications.
- **Security / restricted:** SOC, Red Team, Secure Core.
- **Technical / specialist:** Cryptography, Engineering, Quantum, Advanced Compute.

Production VI compiles one reusable wall/glass/ceiling kit for those families rather than authoring hundreds of unique walls.

## Room hero composition

- Reception: identity feature wall, premium arrival threshold, lounge + credential lane.
- Central Ops: command dais, main situation wall, WS04 hero inset, clear operations aisle.
- Foundations: evidence wall + review zone + learning bays.
- Crypto: symmetric/asymmetric spatial split + trust divider + key/trust wall.
- Communications: channel spine + route wall + endpoint zone.
- SOC: trace-table halo + evidence wall + preservation bay + analyst hierarchy.
- Red Team: Authorise → Target/Scope → Operate spatially legible.
- Engineering: assembly/test zones + overhead service structure + workshop wall.
- Quantum: lab island + optical spine + Alice→Eve→Bob relationship + observation glass + overhead ring.
- Advanced Compute: cold aisle + data spine + processing wall.
- Secure Core: protected plinth + concentric security rings + shield piers; deliberately sparse.

## Material target

Bundled Production VI uses deterministic tileable textures for graphite panels, light stone, dark floor, technical floor, brushed metal, acoustic panel and concrete. `Tools/Fetch-PolyHaven-PBR.ps1` is an optional CC0 intake for higher fidelity replacement maps; the live build never depends on that download succeeding.
